# ADR 002 — Verifier separation

Accepted for implementation 2026-10-11; PI review pending. Model JSON accepts CandidateClaim
only. Deterministic registry validates every authorized record, hash, scope and typed predicate.
Only this code creates verification decisions. Reports render generated factual observations,
never candidate explanations as proof. Analyst inference remains unverified. Independent
human annotations remain necessary to assess intent and research efficacy.
