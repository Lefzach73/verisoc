# Public source companion

This repository is exported from `Lefzach73/verisoc-research` at source commit
`ddb618df1f6abff365638e55dd6660b206b9c700` (12 October 2026). It begins a new public Git
history. The original research repository, commits, raw observations and diagnostic records remain
preserved privately. Public source visibility is not independent scientific acceptance.

`PUBLIC_EXPORT_MANIFEST.json` records the SHA-256 of every original tracked file, its copied, relocated,
modified or omitted status, and the public hash of included files. `make verify-export` checks all
included original bytes. Runtime Python/HTML, tests, synthetic fixtures, dependency pins and license
are preserved. A synthetic contamination inventory is relocated into `config/` for the offline
workflow. No original study is rewritten.

Omitted material includes private operator-path diagnostics, account/CI receipts, historical research
instructions, paid-study configurations, archived studies, duplicate source snapshots and unused
study-specific scripts. Their original file hashes remain listed for provenance; their contents and
Git history are not included. The public companion is not a replacement for the complete frozen
study archive and cannot independently replay omitted historical model responses.

New presentation files provide a concise README, usage and reproduction instructions, public CI,
acceptance results, security/contribution guidance and this export record. Existing research
limitations and original MIT licensing remain explicit. Historical result summaries are labeled
as historical and are not newly measured by this export.

The export manifest is provenance, not a signature or third-party attestation. A party who can
replace both the source and manifest can change both. Keep the source commit and independent
copies when stronger custody is required.
