# Contributing

Start with `make setup`, `make lint`, `make test-all` and `make verify-export`. For database
changes, also run the explicit temporary PostgreSQL integration suite. Preserve evidence lineage,
tenant/RLS boundaries, conservative reports and separation of runtime from evaluation labels.
Include a focused regression check for changes to a trust boundary.

This source companion starts a clean public history; the original private research archive is
preserved. Document changes to exported source in the manifest rather than claiming unchanged
provenance. New experiments need new inputs, output directories and stated assumptions.
Never silently retune frozen labels, thresholds or prior study results.

AI coding assistance was used for implementation, testing and documentation. Human methodological,
implementation and review contributions must be attributed according to actual work. Repository
ownership or a Git author field does not establish sole invention or independent scientific review.
Do not invent reviewers, users, adoption, approvals or coauthor contributions.

Do not contribute customer telemetry, credentials, executed payloads or externally licensed data
without appropriate rights. Hostile strings in tests remain inert data. Hosted providers are opt-in
and metered; default commands and CI must never invoke them. This project has no remediation or
infrastructure-control component.
